# Комплекс Лабораторных Работ по Программированию на языке C

Репозиторий содержит академический комплекс лабораторных работ, направленный на глубокое изучение системного программирования на языке C, проектирование переиспользуемых модулей и библиотек, управление динамической памятью, разработку собственных структур данных, а также интеграцию низкоуровневого кода с высокоуровневыми экосистемами (Python/Tkinter).

---

## 🛠 Чему я научился в ходе выполнения проекта

Данный курс покрывает полный цикл разработки ПО: от простейших линейных алгоритмов до создания событийно-ориентированных GUI-приложений и динамически загружаемых библиотек (`.so`/`.dll`).

### 1. Низкоуровневая работа с памятью и структурами данных
* **Статические и динамические массивы:** Реализация алгоритмов вставки, удаления, фильтрации и сортировки элементов с ручным контролем границ.
* **Многомерные массивы (Матрицы):** Освоение различных схем выделения динамической памяти под матрицы (одним сплошным куском, массивом указателей на строки), реализация эффективных матричных операций.
* **Связные списки (Linked Lists):** Создание кастомных линейных односвязных списков с поддержкой операций сортировки, вставки, удаления, разворота и итерации по элементам.
* **Ассоциативные массивы (Хэш-таблицы / Словари):** Проектирование абстрактного типа данных (ADT) "Ассоциативный массив" в двух различных вариациях реализации (динамический массив структур vs связный список узлов `key-value`), инкапсулируя внутреннее представление от пользователя.

### 2. Строковая обработка и парсинг текста
* **Безопасная работа со строками:** Глубокое понимание нуль-терминированных строк (`char *`), ручная реализация стандартных функций (`strlen`, `strcpy`, `strchr`, `strspn`, `strcspn`, `strpbrk`).
* **Парсинг и токенизация:** Написание алгоритмов разделения текста на слова, валидации числовых форматов, обработки текстов переменной длины и потокового ввода.
* **Форматированный ввод-вывод:** Реверс-инжиниринг и написание собственной упрощенной версии системной функции `snprintf` с поддержкой спецификаторов формата (`%s`, `%d`, `%c`, `%x` и т.д.) и защитой от переполнения буфера.

### 3. Файловый и потоковый ввод-вывод
* Текстовый и двоичный (бинарный) ввод-вывод с обработкой ошибок доступа, конца файла (`EOF`) и повреждения структуры данных.
* Реализация алгоритмов модификации бинарных файлов "на месте" (внутри файла) с помощью `fseek` и `ftell`.

### 4. Модульность и создание собственных библиотек
* **Статическое и динамическое связывание:** Разделение кода на логические модули, написание корректных заголовочных файлов (`.h`), компиляция объектных файлов, статических архивов (`.a`) и разделяемых динамических библиотек (`.so`).
* **Кросс-языковое взаимодействие (FFI):** Использование модуля `ctypes` в Python для загрузки скомпилированных C-библиотек, передачи указателей (`POINTER(c_int)`) и вызова производительных вычислительных ядер из графического интерфейса на Python (Tkinter).

### 5. Инженерная культура и качество кода
* **Тестирование ПО (TDD / CI):**
    * *Функциональное тестирование:* Написание автоматизированных Bash-скриптов для прогона позитивных и негативных тестов (`pos_case.sh`, `neg_case.sh`, `func_tests.sh`) с валидацией кодов возврата и сравнением вывода программ с помощью кастомных компараторов.
    * *Модульное тестирование:* Использование фреймворка `Check` для написания юнит-тестов на отдельные функции (`Suite`, `TCase`).
* **Отладка и Профилирование:** Нахождение утечек памяти, неопределенного поведения и ошибок работы с указателями с помощью санитайзеров компилятора (`AddressSanitizer (ASan)`, `MemorySanitizer (MSan)`, `UndefinedBehaviorSanitizer (UBSan)`) и утилиты `Valgrind`. Вычисление покрытия кода тестами через `gcov`.
* **Автоматизация сборки:** Написание гибких `makefile` и скриптов сборки для различных конфигураций (`build_debug.sh`, `build_release.sh`).

## 📂 Структура репозитория и эволюция модулей

Проект разбит на логические блоки (`lab_XX`), каждый из которых углубляет стек используемых технологий:

* **`lab_01`** — Базовые конструкции C, типы данных, циклы, функции, условные операторы и математические вычисления.
* **`lab_02`** — Одномерные статические массивы: алгоритмы поиска, вставки, удаления и сортировки.
* **`lab_03`** — Статические и динамические двухмерные массивы (Матрицы).
* **`lab_04`** — Обработка строк и символов, реализация кастомных аналогов `string.h`.
* **`lab_05`** — Работа с файлами (текстовые потоки и бинарные структуры данных).
* **`lab_06`** — Массивы структур, сортировка, текстовые базы данных с фиксированным и переменным описанием полей.
* **`lab_07`** — Динамические массивы, фильтрация данных, углубленное тестирование качества кода, написание модульных тестов с `Check`.
* **`lab_08`** — Динамические матрицы, продвинутые способы распределения памяти, перемножение и детерминанты разреженных/плотных матриц.
* **`lab_09`** — Динамическое управление памятью в структурах данных, глубокое копирование строк, предотвращение утечек (`free`).
* **`lab_10`** — Абстрактные структуры данных:
    * `lab_10_01_01` & `lab_10_02_06`: Односвязные списки, обработка списков книг, разреженные матрицы на базе связных списков.
    * `lab_10_03_*`: Ассоциативный массив (реализации через массивы указателей и через связанные цепочки узлов).
* **`lab_11`** — Написание собственной системной функции форматирования `my_snprintf.c` с разбором вариадических аргументов (`va_list`).
* **`lab_12`** — Создание разделяемых динамических библиотек и интеграция:
    * `lab_12_03_1`: Динамическая загрузка библиотек сортировки и фильтрации.
    * `lab_12_03_2`: Высокопроизводительное вычислительное ядро на Си (`arr_lib.c`) + кроссплатформенный графический интерфейс на Python с использованием `tkinter` и `ctypes`.

## 🚀 Архитектура типичного подмодуля

Каждая продвинутая лабораторная работа оформлена в соответствии с индустриальными стандартами организации Си-проектов:

```text
lab_XX_YY_ZZ/
├── inc/                      # Заголовочные файлы (*.h)
├── src/                      # Исходный код (*.c)
├── out/                      # Объектные файлы (*.o) и файлы покрытия (*.gcda)
├── unit_tests/               # Юнит-тесты на фреймворке Check
├── func_tests/               # Функциональные тесты
│   ├── data/                 # pos_*_in.txt, pos_*_out.txt, neg_*_in.txt
│   └── scripts/              # Скрипты автоматического тестирования и компараторы
├── makefile                  # Инструкции сборки проекта
├── build_debug.sh            # Сборка с флагами отладки и gcov
├── build_debug_asan.sh       # Сборка с AddressSanitizer
└── clean.sh                  # Скрипт очистки артефактов компиляции
